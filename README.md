## Features

The portfolio is structured into several key sections accessible via smooth scrolling navigation:

Home: A dynamic introduction using Framer Motion for engaging animations.

About: Detailed information on education (currently pursuing a Bachelor of Arts in Computer Science at FIU, minoring in Engineering Mathematics) and a passion for blending creativity and technology, particularly in music production.

Projects: Displays highlighted projects with descriptions, tags, and visuals.

Skills: A comprehensive list of technical proficiencies.

Experience: A visual timeline of education and professional experience using react-vertical-timeline-component.

Contact: A form that uses Next.js Server Actions and Resend for reliable email delivery.

## Getting Started
Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites
Node.js (LTS version recommended)

npm or yarn (The project uses npm, as indicated by package-lock.json).

### Installation

Clone the repository:

### Bash

git clone [YOUR_REPO_URL]
Navigate to the project directory:

Bash
```
cd portfolio
```
Install dependencies:

Bash
```
npm install
# or
yarn install
```
Create a .env.local file in the root directory and add your Resend API Key for the contact form functionality:

RESEND_API_KEY="your_resend_api_key_here"
Running the Project

To start the development server:

Bash
```
npm run dev
# or
yarn dev
```
The application will be accessible at http://localhost:3000.
